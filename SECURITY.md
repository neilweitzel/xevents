# Private reporting

Use [GitHub private reporting](https://github.com/neilweitzel/xevents/security/advisories/new)
for a security flaw, privacy concern, personal information, credentials,
affected-party identity or sensitive evidence. Do not put that material in a
public issue or pull request.

For a non-sensitive question or correction about a published aggregate,
classification, export, app behavior or public methodology, use the
[research correction form](https://github.com/neilweitzel/xevents/issues/new?template=correction.yml).

The operator reviews GitHub notifications on business days. Acknowledgement
targets in the dispute process are operating targets, not a replacement for
applicable legal obligations.
